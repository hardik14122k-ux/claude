About this app

TalentTrack is a Flask + SQLite recruitment tracker. Candidate CVs are parsed on the server via pypdf and a library of heuristics (skills, sections, date ranges).

Pipeline stages

  • Sourced — candidate identified
  • Screening — recruiter call / resume review
  • Interview — technical / onsite loops
  • Offer — offer extended
  • Hired / Rejected — terminal
